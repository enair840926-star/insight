# 매크로 데스크 피드에서 아직 못 채우는 것

`core/feed.py`가 내보내는 수치형 팩터 8개 중 셋이 비어 있다. **소스가
없어서가 아니라 이 환경에서 못 받아서다.** 그 구분이 무너지면 "그 값은
구할 수 없다"는 잘못된 결론이 남아 다음 사람이 같은 길을 다시 판다.

| 팩터 | 원래 소스 | 지금 상태 |
|---|---|---|
| `realYield` | FRED DFII10 | 막힘. **대체 소스 확인함** (아래) |
| `inflation` | FRED T10YIE | 막힘. **대체 소스 확인함** (아래) |
| `rateDiff` | 유로존(독일) 10년물 | 미해결 |

---

## realYield · inflation — 방법은 찾았고 키가 없다

**FMP의 `economics-indicators` name=`inflationRate`가 FRED T10YIE와 같은
값을 일별로 준다.** 월별 CPI가 아니라 기대인플레(10년 브레이크이븐)다.

제보자가 2026-08-23에 `fred.stlouisfed.org/series/T10YIE`와 직접 대조해
겹치는 다섯 날짜가 소수점까지 일치하는 것을 확인했고, 이쪽에서도 FMP를
다시 호출해 같은 값을 받았다.

| 날짜 | FMP `inflationRate` | 10년 명목(`treasury-rates.year10`) | 실질금리 |
|---|---|---|---|
| 2026-08-21 | 2.34 | 4.74 | **2.40** |
| 2026-08-20 | 2.34 | 4.69 | **2.35** |
| 2026-08-19 | 2.30 | 4.65 | **2.35** |
| 2026-08-18 | 2.30 | 4.71 | 2.41 |
| 2026-08-17 | 2.28 | 4.72 | 2.44 |

```
inflation = inflationRate                       (= T10YIE)
realYield = treasury-rates.year10 - inflationRate
```

`realYield`는 정의상 DFII10과 같다(명목 − 기대인플레 = 실질).
`treasury-rates`도 같은 `economics` 엔드포인트이고 일별로 month1~year30
전 구간을 준다.

### 왜 아직 안 붙였나

**이 환경에 FMP API 키가 없다.** 확인한 것:

- `.env` 파일이 없다
- 환경변수에 `FMP`·`FINANCIALMODEL` 계열이 없다
- `.github/workflows/*.yml`이 넘기는 시크릿은 `DART_API_KEY`·`ECOS_API_KEY`·
  `EIA_API_KEY`(+알림용 셋)뿐이다

위 숫자는 **MCP 도구**로 받은 것이다. 수집기(`collectors/*.py`)는
`core/http.fetch_json`으로 평문 HTTP를 쓰므로 그 경로가 아니다.

### 키가 생기면 할 일

1. `FMP_API_KEY`를 `.env`(PC)와 GitHub Secrets(클라우드) 양쪽에 넣는다.
   **Secrets의 Secret 칸에는 값만 넣는다** — 이름을 값에 같이 넣어 세 키가
   통째로 거부된 적이 있다.
2. `.github/workflows/collect.yml`의 수집 단계 `env:`에 `FMP_API_KEY`를 넣는다.
3. `tools/probe.py`에 **먼저** 넣고 러너에서 재 본다. PC에서 되는 것이
   러너에서 된다는 보장이 없고 그 반대도 마찬가지다.
   **200을 성공으로 세지 마라** — 본문에 값이 실렸는지까지 본다.
4. REST 엔드포인트의 파라미터 이름이 MCP와 다를 수 있다. 실호출로 확인한다.
5. `core/feed.py`의 `put("realYield", ...)`·`put("inflation", ...)`을 넣고
   `_WHY_MISSING`에서 두 줄을 뺀다.

**넣을 때도 `value`만 넣는다.** 실질금리 숫자만 넘기고 "금에 역풍이다"
같은 판정은 매크로 데스크가 자기 밴드로 하게 둔다 — 그게 그쪽 스코어보드가
자기 룰셋을 채점하게 하는 유일한 방법이다.

## levels 키 이름 — 옮기는 중

`XAUUSD`·`USOIL`은 현물 표기인데 담기는 값이 **선물**이다
(`config.MACRO_SYMBOLS`: 금 `GC=F`, WTI원유 `CL=F`). 2026-08-21 스냅샷에서
금은 `Gold Dec 26`, 원유는 `Crude Oil Sep 26`이었다.

격차는 고정이 아니다. 제보 실측(2026-08-10~14)에서 금 현물과 선물의 차이가
**30.6 ~ 73.2포인트**로 흔들렸고 **8/11에는 일간 방향까지 반대였다**
(현물 −21.18 / 선물 +21.4). 만기가 가까워지면 줄고 롤오버 때 튄다 —
고정 오프셋으로 환산할 수 없다.

선물 쪽 값은 FMP `GCUSD`로 재확인했다(8/10~8/14: 4419.7 · 4441.1 · 4467.5 ·
4420.4 · 4437.3). 현물 쪽은 이 환경에서 못 받아 제보 값을 인용한다.

### 지금 한 것

- 참 이름 `XAUUSD_FUT`·`USOIL_FUT`를 내보낸다
- 옛 키 `XAUUSD`·`USOIL`도 **같은 값으로 함께** 내보내고
  `deprecated: true`·`replacedBy`를 붙인다 — 받는 쪽은 다른 저장소라
  한 번에 못 바꾼다. 지우면 조용히 깨진다.
- 각 level에 `contract`를 실어 보낸다(`"Gold Dec 26"`). 수집기가 이미 알던
  값인데 피드에서 버리고 있었다 — 롤오버로 계약이 바뀌면 값이 튀는데
  받는 쪽에 알 방법이 없었다.
- 최상위 `notices` 배열에 옮기라는 말을 남긴다.

### 현물로 바꾸는 것은 **못 한다** — 러너에서 다 재 봤다 (2026-08-24)

| 후보 | 결과 |
|---|---|
| 야후 `XAUUSD=X` | HTTP 404 `symbol may be delisted` |
| 야후 `XAU=X` | HTTP 404 |
| stooq 일봉 CSV | 자바스크립트 요구 페이지(봇 차단) |
| exchangerate.host | API 키 필요 |
| **LBMA 오후 고시** | **OK** — 다만 하루 한 번 고시 |
| **gold-api 현재가** | **OK** — 다만 이력 없음 |

같은 회차에서 야후 차트(AAPL)는 OK였다. **야후가 막힌 게 아니라 그 심볼이
없는 것이다.** (이 컨테이너에서는 야후가 통째로 403이라 여기선 이 구별이
안 된다 — 러너에서 재야 했던 이유다.)

**되는 둘도 대체가 안 된다.** 픽은 20일선·20일 변동성·5일/20일 추세를
**종가 시계열**에서 뽑는다.

- `gold-api`는 현재가만 준다 — 시계열이 없어 그 자리를 못 채운다.
- `LBMA`는 이력이 통째로 오지만 하루 한 번 고시다. 런던 오후 고시는
  14:00 UTC 무렵인데 **저녁 수집이 12:15 UTC**라 그날 값이 아직 없다.
  바꾸면 저녁 스냅샷의 '당일 등락'이 하루 묵은 값이 된다 — 지금보다 나쁘다.

그래서 **픽 계열은 선물 그대로 두고 현물은 참고값으로 따로 낸다.**

- `collectors/gold_spot.py` — gold-api에서 현재가만 받는다. 실패해도
  수집은 계속한다(참고값이라 없다고 실패가 아니다).
- 화면: 매크로 탭 맨 위 `금 — 선물과 현물` 카드에 선물·현물·격차를 나란히.
- 피드: `context.goldSpot`에 `last`·`vsFutures`. **`levels`가 아니다** —
  엔진의 position 계산이 `last`/`prevClose`를 쌍으로 쓰는데 현물 소스에
  이력이 없어 `prevClose`를 못 만든다. 없는 값을 채우면 등락 0%가 되어
  '변화 없음'이라는 없는 근거가 생긴다.

**격차는 같은 스냅샷 안에서만 본다.** 어제 격차와 이으면 안 된다 —
만기가 가까워지면 줄고 롤오버 때 튄다.

### 나중에 진짜 현물로 바꾸려면

연속 시세 + 일별 이력을 함께 주는 소스가 필요하다. 후보는 키가 있는
곳들이다(Twelve Data, Alpha Vantage, metals.dev, FMP forex — FMP는 현재
요금제에서 forex가 막혀 있다). 키를 넣게 되면 `tools/probe.py`에 **먼저**
넣고 러너에서 재라.

바꾸는 날에는 **금 가격 계열이 한 번 ~50~70포인트 점프한다.** 실제 움직임이
아닌데 그 사이에 열려 있던 금 픽이 그것을 진짜 등락으로 채점한다. 표본
하나짜리 오염이지만 기록에 남으므로 바꾼 날짜를 여기 적어 둘 것.

### 예전에 적어 둔 것 — 안 한 것 (참고)

`MACRO_SYMBOLS["금"]`을 `XAUUSD=X`로 바꾸는 것은 **하지 않았다.** 그 심볼의
OHLC 품질과 `prev_close` 정의를 실호출로 검증하지 않았기 때문이다.
검증 없이 바꾸면 **이름만 맞고 값이 틀리는**, 지금보다 나쁜 상태가 된다.

바꾸려면 먼저 `tools/probe.py`에 넣고 러너에서 며칠 재서
`GC=F`와 나란히 놓고 봐야 한다.

### 원유는 판단이 갈린다

원유는 현물 개념이 금만큼 명확하지 않아 선물을 쓰는 것이 오히려 맞을 수
있다. 그래서 심볼은 그대로 두고 **이름만** `USOIL_FUT`로 했다.

### 나스닥선물도 같은 구조다

`NAS100`에 담기는 값은 `Nasdaq 100 Sep 26` 선물이다. `NAS100`은 보통
지수를 가리키는 이름이라 금·원유와 같은 종류의 어긋남이지만, 제보에
없었고 이름에 '선물'이 드러나지 않아도 지수와 선물의 격차는 금만큼
크지 않다. `contract` 필드가 실려 나가므로 받는 쪽이 판단할 수 있다.
