# 인사이트 갱신하는 법

숫자 데이터는 매일 08:00 / 21:30에 자동으로 갱신되지만, **인사이트 글은
저절로 바뀌지 않는다.** 누군가 써야 한다. 아래 세 가지 방법이 있다.

---

## 1. 폰에서 Claude에게 시키기 (요금 없음, 가장 편함)

폰 브라우저로 **https://claude.ai/code** 를 열고 이 저장소
(`enair840926-star/insight`)를 연결한다. 한 번만 해 두면 된다.

그다음 아래를 복사해서 붙여넣는다.

```
cloud/ 에 있는 최신 prompt_*.txt 를 읽고, 그 안의 요청 형식대로
insights/insight_kr.md 를 다시 써서 커밋해줘.

- 데이터에 없는 종목·숫자를 지어내지 마라
- 회고가 아니라 다음 장에 대비하는 글로 쓴다
- 문체는 존댓말, 폰에서 읽으니 문단은 짧게
```

`insight_kr.md` 자리에 원하는 걸 넣는다 — `insight_us.md`,
`insight_macro.md`, `insight_coin.md`.

전부 한 번에 하려면:

```
cloud/ 의 최신 prompt_*.txt 4개를 읽고 insights/ 의 인사이트 4개를
전부 다시 써서 커밋해줘. 각 프롬프트 안의 요청 형식을 따르고,
데이터에 없는 내용은 지어내지 마라.
```

커밋하면 1분 안에 앱에 반영된다.

---

## 2. 폰에서 직접 고치기 (요금 없음)

앱의 인사이트 카드에서 **고치기**를 누르면 깃허브 편집기가 열린다.
한 줄 고치거나 메모를 덧붙일 때 쓴다.

---

## 3. PC에서 API로 생성 (요금 발생)

`.env` 에 `ANTHROPIC_API_KEY` 를 넣고:

```
git pull
python insight.py
git add insights; git commit -m "인사이트 갱신"; git push
```

클라우드가 받아 둔 데이터를 쓰므로 다시 수집하지 않는다.
자산군만 고르려면 `python insight.py kr macro`.

---

## 왜 자동이 아닌가

인사이트는 LLM이 분석하는 것이라 부를 때마다 API 요금이 붙는다.
돌리는 위치(PC/클라우드)의 문제가 아니라 API를 부르느냐의 문제라,
예약을 걸어도 요금은 그대로다. 그래서 데이터 수집만 자동으로 두고
글은 필요할 때 만든다.

`cloud/` 에는 항상 최신 데이터가 있으므로, 언제 만들든 그 시점의
최신 숫자로 쓰인다.
