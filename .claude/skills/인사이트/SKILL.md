# 자산 인사이트 갱신

수집기가 만들어 둔 프롬프트를 읽고, 그 안의 요청 형식대로 인사이트를
써서 커밋한다. 데이터를 새로 수집하지 않는다 — 클라우드가 장 시간에
맞춰 이미 받아 뒀다.

## 저장소 위치

다른 폴더에서 불릴 수 있으므로 먼저 저장소를 찾는다.

1. 현재 폴더에 `insights/` 와 `cloud/` 가 있으면 여기가 저장소다.
2. 없으면 `C:\Users\enair\Desktop\claude\asset-insight` 를 쓴다 (PC).
3. 둘 다 아니면(claude.ai/code 등) 연결된 저장소 루트를 쓴다.

이후 모든 경로는 저장소 루트 기준이다.

## 인자

`$ARGUMENTS` 에 자산군이 들어온다. 비어 있으면 **네 개 전부**.

| 인자 | 대상 |
|---|---|
| (없음) | kr, us, macro, coin |
| `kr` | 국장 |
| `us` | 미장 |
| `macro` | 매크로 |
| `coin` | 코인 |
| `kr macro` | 여러 개 지정 |

"국장", "미장", "매크로", "코인" 같은 한글도 같은 뜻으로 받는다.

## 순서

### 1. 최신 프롬프트를 찾는다

각 자산군마다 `cloud/prompt_{market}_*.txt` 와 `data/prompt_{market}_*.txt`
중 **파일명에 박힌 시각이 가장 늦은 것**을 고른다.

```
prompt_kr_20260805_0800.txt   ← 20260805_0800 부분으로 비교
```

**수정 시각(mtime)으로 고르지 마라.** git이 파일을 내려받으면 mtime이
받은 시각으로 찍혀서, 아침에 수집된 것이 방금 만든 것처럼 보인다.

파일이 없으면 그 자산군은 건너뛰고 사용자에게 알린다. 수집이 아직
안 돈 것이므로 직접 수집하려 하지 말고 사실만 전한다.

### 2. 프롬프트를 읽고 그대로 따른다

프롬프트 파일 안에 `## 요청` 섹션이 있고, 거기에 형식·규칙이 전부
적혀 있다. **그 지시를 그대로 따른다.** 이 파일에 다시 옮겨 적지
않는 이유는, 수집기가 형식을 바꾸면 여기가 낡기 때문이다.

특히 지킬 것:

- **회고가 아니라 대비.** 지나간 장을 복기하지 말고 다가올 장에서
  무엇을 볼 것인지 쓴다.
- **데이터에 있는 것만.** 프롬프트에 없는 종목·숫자를 지어내지 않는다.
  모르면 "데이터 없음"이라고 적는다.
- **수집 실패 표시를 존중한다.** 프롬프트에 "DART 수집 실패"나
  "조회 실패" 같은 문구가 있으면, 그 항목을 "없었다"로 서술하지 않는다.
  일어나지 않은 것이 아니라 받지 못한 것이다.
- **매수·매도를 권하지 않는다.** "무엇을 보라"까지가 범위다.
- 문체는 존댓말. 폰에서 읽으므로 문단은 짧게, 숫자 대조는 표로.

### 3. 파일에 쓴다

`insights/insight_{market}.md` 에 쓴다. **`data/` 가 아니다** —
`data/` 는 .gitignore 대상이라 커밋되지 않고, 클라우드가 대시보드를
다시 구울 때 지워진다.

### 4. 커밋하고 푸시한다

```
git add insights
git commit -m "인사이트 갱신 <자산군>"
git push
```

푸시하면 `인사이트 반영` 워크플로가 대시보드를 다시 굽는다.
약 1분 뒤 폰 앱에 반영된다.

푸시가 거부되면 `git pull --rebase` 후 다시 시도한다. 클라우드가
먼저 커밋했을 수 있다.

### 5. 사용자에게 보고한다

- 어느 자산군을 갱신했는지
- 각각 어느 시점 데이터를 썼는지 (프롬프트 파일명의 시각)
- 1분 뒤 앱에 반영된다는 것
- 데이터가 오래됐으면(12시간 이상) 그 사실

앱 주소: https://enair840926-star.github.io/insight/

## 하지 말 것

- **수집기를 돌리지 마라.** `python collect_*.py` 나 `python run.py` 를
  실행하지 않는다. 수집은 클라우드가 예약으로 한다. 폰에서 부른
  경우에는 실행 자체가 안 되기도 한다.
- **`insight.py` 를 쓰지 마라.** 그건 Anthropic API를 호출해서 요금이
  붙는다. 이 스킬은 직접 읽고 쓰는 무료 경로다.
- 프롬프트 원문을 사용자에게 그대로 붙여넣지 마라. 수만 자다.
