# 자산 인사이트 갱신

수집기가 만들어 둔 프롬프트를 읽고, 그 안의 요청 형식대로 인사이트를
써서 커밋한다. 데이터를 새로 수집하지 않는다 — 클라우드가 장 시간에
맞춰 이미 받아 뒀다.

> **이 파일이 정본이다.** `~/.claude/skills/인사이트/SKILL.md`는 여기를
> 가리키는 포인터일 뿐이니 거기에 사본을 만들지 마라. 예전에 사본이
> 있었고, 2026-08-08에 '오늘의 픽'이 들어갈 때 이 파일만 고쳐서 옛
> 규칙("매수·매도를 권하지 않는다")이 살아 돌아온 적이 있다.

## 저장소 위치

다른 폴더에서 불릴 수 있으므로 먼저 저장소를 찾는다.

1. 현재 폴더에 `insights/` 와 `cloud/` 가 있으면 여기가 저장소다.
2. 없으면 `C:\Users\enair\Desktop\claude\asset-insight` 를 쓴다 (PC).
3. 둘 다 아니면(claude.ai/code 등) 연결된 저장소 루트를 쓴다.

이후 모든 경로는 저장소 루트 기준이다.

## 인자

`$ARGUMENTS` 에 자산군이 들어온다. 비어 있으면 **네 개 전부**.

| 인자 | 대상 |
|---|---|
| (없음) | kr, us, macro, coin |
| `kr` | 국장 |
| `us` | 미장 |
| `macro` | 매크로 |
| `coin` | 코인 |
| `kr macro` | 여러 개 지정 |
| `auto` / `새것만` | **데이터가 인사이트보다 새로운 것만** |

"국장", "미장", "매크로", "코인" 같은 한글도 같은 뜻으로 받는다.

### auto 모드

예약 실행에서 쓴다. 시각만 보고 돌면 수집보다 먼저 돌아 헛도는데
(GitHub 예약이 한 시간까지 밀린다), 새 데이터가 있을 때만 쓰면
순서에 상관없이 옳게 동작한다.

대상은 눈대중으로 고르지 말고 도구에 물어본다:

```
python tools/pending.py
```

자산군 이름을 공백으로 구분해 출력한다. **빈 줄이면 할 일이 없다는
뜻이니 아무것도 쓰지 말고 조용히 끝낸다.** 이유까지 보려면 `-v`.

`-v`에 **"대기 (이번 세션 수집 전)"** 이 뜨는 경우가 있다. 새 데이터가
있는데도 일부러 안 쓰는 것이다 — 개장 전 수집 창 안인데 이번 세션
수집이 아직 안 왔으므로, 지금 쓰면 곧 도착할 데이터에 덮여 버려진다.
다음 루틴이 받아 간다. **억지로 쓰지 마라.**

장이 열리면 더 기다리지 않고 쓴다. 수집이 아예 안 올 수도 있으니
무한정 미루지는 않는다.

## 순서

### 0. auto 모드면 대상을 먼저 정한다

`python tools/pending.py` 를 돌려 나온 자산군만 대상으로 삼는다.
출력이 비어 있으면 **여기서 끝낸다.** 커밋도 보고도 길게 하지 말고
"새 데이터 없음"만 알린다.

### 1. 최신 프롬프트를 찾는다

각 자산군마다 `cloud/prompt_{market}_*.txt` 와 `data/prompt_{market}_*.txt`
중 **파일명에 박힌 시각이 가장 늦은 것**을 고른다.

```
prompt_kr_20260805_0800.txt   ← 20260805_0800 부분으로 비교
```

**수정 시각(mtime)으로 고르지 마라.** git이 파일을 내려받으면 mtime이
받은 시각으로 찍혀서, 아침에 수집된 것이 방금 만든 것처럼 보인다.

파일이 없으면 그 자산군은 건너뛰고 사용자에게 알린다. 수집이 아직
안 돈 것이므로 직접 수집하려 하지 말고 사실만 전한다.

### 2. 프롬프트를 읽고 그대로 따른다

프롬프트 파일 안에 `## 요청` 섹션이 있고, 거기에 형식·규칙이 전부
적혀 있다. **그 지시를 그대로 따른다.** 이 파일에 다시 옮겨 적지
않는 이유는, 수집기가 형식을 바꾸면 여기가 낡기 때문이다.

특히 지킬 것:

- **회고가 아니라 대비.** 지나간 장을 복기하지 말고 다가올 장에서
  무엇을 볼 것인지 쓴다.
- **데이터에 있는 것만.** 프롬프트에 없는 종목·숫자를 지어내지 않는다.
  모르면 "데이터 없음"이라고 적는다.
- **수집 실패 표시를 존중한다.** 프롬프트에 "DART 수집 실패"나
  "조회 실패" 같은 문구가 있으면, 그 항목을 "없었다"로 서술하지 않는다.
  일어나지 않은 것이 아니라 받지 못한 것이다.
- **'오늘의 픽'은 계산된 결과를 그대로 쓴다.** 프롬프트에 순위·점수·
  근거가 이미 박혀 있다. 순서를 바꾸거나 다른 대상으로 갈아치우지
  마라 — 고르는 일은 규칙이 끝냈고, 여기서 할 일은 사람 말로 옮기는
  것이다. 근거가 약해 보이면 조용히 바꾸지 말고 그 사실을 글에 적어라.
  **개수는 여기 적지 않는다** — 자산군마다 다르고(주식 3종, 코인 2종,
  매크로 4종) 바뀐다. 블록 제목에 몇 종인지 찍혀 있으니 그 수를 따르고
  하나도 빼먹지 마라. 여기 숫자를 베껴 적었다가 매크로가 넷으로 늘었을 때
  낡은 채로 남았다 — 형식의 정본은 프롬프트의 `## 요청` 섹션이다.
- **'피할 것'을 상승 픽처럼 쓰지 마라.** 국장·미장은 오를 근거가 두꺼운
  것만 뽑고, 후보가 모자라면 남는 칸이 '피할 것'으로 채워진다. 그건
  내릴 근거가 두꺼운 종목이니 제목에서부터 구분해서 쓴다.
  코인·매크로는 선물이라 상승·하락 양쪽이 다 픽으로 나온다.
- **반대 근거가 함께 있으면 양쪽을 다 적는다.** 근거 목록에 부호가
  붙어 있다. 플러스만 옮기면 글이 데이터보다 세진다.
- **점수는 상승 확률이 아니라 근거의 두께다.** "오를 확률이 높다"가
  아니라 "오를 근거가 이만큼 쌓였다"로 쓴다.
- **'근거가 깨지는 지점'을 그대로 옮기되 손절선으로 쓰지 마라.** 그 값이
  무너지면 근거 하나가 사라진다는 뜻이지 팔라는 신호가 아니다.
  손절가·목표가·비중은 어디에도 쓰지 않는다.
- **방향은 픽에만 붙인다.** 픽 밖의 항목은 "무엇을 보라"까지가 범위다.
  사라·팔라·비중·진입가·목표가·손절가는 어디에도 쓰지 않는다.
  방향에는 **틀렸다고 볼 조건**을 반드시 함께 적는다.
- 문체는 존댓말. 폰에서 읽으므로 문단은 짧게, 숫자 대조는 표로.
- **전문용어를 그대로 쓰지 않는다.** 프롬프트 끝의 용어 규칙에도
  적혀 있지만 긴 글에 묻혀 놓치기 쉬우니 여기 다시 적는다.
  폰에서 훑는 글이라, 용어를 떠올려야 읽히는 문장은 실패한 문장이다.

  | 쓰지 마라 | 이렇게 |
  |---|---|
  | 플래트닝 / 커브가 눕는다 | 장단기 금리차 축소 |
  | 스티프닝 / 스티프 | 장단기 금리차 확대 |
  | 백워데이션 | 지금 물건이 나중보다 비쌈 |
  | 콘탱고 | 나중이 더 비쌈 |
  | 재고가 타이트 | 재고 부족 |
  | 롱숏비 5.85 | 롱이 숏의 5.85배 |

  제목에 넣는 것이 특히 나쁘다 — 목록만 훑는 사람이 제일 먼저 본다.

### 3. 파일에 쓴다

`insights/insight_{market}.md` 에 쓴다. **`data/` 가 아니다** —
`data/` 는 .gitignore 대상이라 커밋되지 않고, 클라우드가 대시보드를
다시 구울 때 지워진다.

### 3.5 검사한다

```
python tools/lint_insight.py
```

전문용어가 남았는지 잰다. 규칙을 프롬프트와 이 파일 양쪽에 적어 뒀는데도
수만 자를 쓰다 보면 계속 되돌아온다. 바라는 대신 재서 막는다.

걸리면 고치고 다시 돌린다. **통과할 때까지 커밋하지 않는다.**
`--fix`는 안전한 것만 자동으로 바꾸고 나머지는 문맥을 봐야 하니 직접 고친다.

제목에 걸린 것은 특히 먼저 고친다 — 목록만 훑는 사람이 제일 먼저 본다.

### 4. 커밋하고 푸시한다

```
git add insights
git commit -m "인사이트 갱신 <자산군>"
git push
```

푸시하면 `인사이트 반영` 워크플로가 대시보드를 다시 굽는다.
약 1분 뒤 폰 앱에 반영된다.

푸시가 거부되면 `git pull --rebase` 후 다시 시도한다. 클라우드가
먼저 커밋했을 수 있다.

### 5. 사용자에게 보고한다

- 어느 자산군을 갱신했는지
- 각각 어느 시점 데이터를 썼는지 (프롬프트 파일명의 시각)
- 1분 뒤 앱에 반영된다는 것
- 데이터가 오래됐으면(12시간 이상) 그 사실

앱 주소: https://enair840926-star.github.io/insight/

## 하지 말 것

- **수집기를 돌리지 마라.** `python collect_*.py` 나 `python run.py` 를
  실행하지 않는다. 수집은 클라우드가 예약으로 한다. 폰에서 부른
  경우에는 실행 자체가 안 되기도 한다.
- **`insight.py` 를 쓰지 마라.** 그건 Anthropic API를 호출해서 요금이
  붙는다. 이 스킬은 직접 읽고 쓰는 무료 경로다.
- 프롬프트 원문을 사용자에게 그대로 붙여넣지 마라. 수만 자다.
