자산 인사이트 앱에서 새로 수집된 데이터가 있으면 인사이트를 다시 쓴다.

저장소: C:\Users\enair\Desktop\claude\asset-insight

순서:
1. 저장소로 이동해 `git pull` 을 먼저 한다.
2. `python tools/pending.py -v` 를 돌린다. 인사이트보다 새로운 데이터가
   있는 자산군만 출력된다.
3. **출력이 비어 있으면 여기서 끝낸다.** 커밋하지 말고 "새 데이터 없음"만
   한 줄로 알린다. 이게 대부분의 경우다 — 저녁에 3번 돌지만 실제로 쓰는 건
   수집이 끝난 직후 한 번뿐이다.
4. 출력된 자산군이 있으면 `인사이트` 스킬을 그 자산군들로 실행한다.
   (스킬 위치: .claude/skills/인사이트/SKILL.md)
5. insights/ 에 쓰고 커밋·푸시한다.

이 작업이 저녁에 3번 도는 이유:
GitHub 예약 수집이 최대 한 시간까지 밀린다. 실측에서 21:30 예약이
한 시간이 지나도 안 돌았다. 시각만 보고 한 번만 돌면 수집 전에 돌아
헛돈다. 여러 번 돌면서 새 데이터가 생긴 순간에만 일하게 한다.

주의:
- 수집기(collect_*.py, run.py)를 실행하지 마라. 수집은 GitHub Actions가 한다.
- insight.py 를 쓰지 마라. API 요금이 붙는다. 직접 읽고 쓴다.
- 코인 데이터를 클라우드에서 받으면 파생 지표 출처가 OKX다(미국 IP에서
  바이낸스가 451로 막힘). 프롬프트에 출처가 적혀 있으니 그대로 따르고,
  펀딩비·롱숏비의 절대 수준을 다른 거래소 수치와 비교하지 않는다.

끝나면 무엇을 갱신했는지(또는 할 일이 없었는지) 한두 줄로 보고한다.
